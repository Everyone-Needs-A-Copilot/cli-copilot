# n8n CLI

**Command:** `copilot n8n`
**Source:** `copilot_cli/services/n8n/`

## Purpose

n8n workflow automation management — create, activate, deactivate, and monitor workflows and executions.

## Commands

| Subgroup | Command | Description | Key Options |
|----------|---------|-------------|-------------|
| `n8n workflows` | `list` | List all workflows | `--active`, `--limit` |
| `n8n workflows` | `get` | Get workflow by ID | `ID` |
| `n8n workflows` | `create` | Create a workflow | `--name`, `--nodes` |
| `n8n workflows` | `activate` | Activate a workflow | `ID` |
| `n8n workflows` | `deactivate` | Deactivate a workflow | `ID` |
| `n8n workflows` | `delete` | Delete a workflow | `ID` |
| `n8n executions` | `list` | List executions | `--limit`, `--workflow-id` |
| `n8n executions` | `get` | Get execution by ID | `ID` |

## Examples

```bash
copilot n8n workflows list
copilot n8n workflows get 42
copilot n8n workflows activate 42
copilot n8n executions list --limit 5
copilot n8n executions list --workflow-id 42
copilot n8n health
```

## Configuration

| Variable | Description | Default |
|----------|-------------|---------|
| `N8N_BASE_URL` | n8n instance URL | Required |
| `N8N_API_KEY` | n8n API key | Required |

## Health Check

```bash
copilot n8n health
```

Checks: Pings the n8n API to verify connectivity and authentication.
