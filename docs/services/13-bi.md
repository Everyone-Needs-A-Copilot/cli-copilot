# Business Intelligence CLI

**Command:** `copilot bi`
**Source:** `copilot_cli/services/bi/`

## Purpose

Business intelligence — data analysis, pattern detection, and KPI calculation from local data sources.

## Commands

| Command | Description | Key Options |
|---------|-------------|-------------|
| `bi analyze` | Run data analysis | `DATA_SOURCE`, `--analysis-type` |
| `bi patterns` | Detect patterns in data | `--pattern-type`, `--sensitivity` |
| `bi kpis` | Calculate KPI metrics | `--metrics`, `--timerange` |
| `bi summary` | Generate data summary | `DATA` |
| `bi health` | Check BI engine availability | — |

## Examples

```bash
copilot bi analyze sales_data --analysis-type trends
copilot bi patterns --pattern-type seasonal --sensitivity high
copilot bi kpis --metrics revenue,churn --timerange 30d
copilot bi summary
copilot bi health
```

## Configuration

No external configuration required. Runs local computations.

## Health Check

```bash
copilot bi health
```

Checks: Validates the BI computation engine is available and functional.
